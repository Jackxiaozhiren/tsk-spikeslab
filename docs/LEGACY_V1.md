# Historical v1.0 boundary

Git tag/release `v1.0` is an immutable historical snapshot from the earlier Information Sciences-era manuscript state. Its manuscript text, figures, result files, and implementation are not the controlling evidence for the current Applied Soft Computing manuscript.

The ASOC rebuild changed both implementation details and the scientific interpretation. In particular, the current manuscript no longer uses the old exact-inference, universal-convergence, BIC-collapse, or general sparsity-superiority narrative. Use `v2.0.0` for the ASOC manuscript and retain `v1.0` only for provenance.
