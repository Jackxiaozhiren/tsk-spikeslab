\noindent\textbf{Manuscript:} Exact Bayesian Spike-and-Slab Inference for Takagi--Sugeno--Kang Fuzzy Systems with Calibrated Model-Averaged Prediction Intervals

\vspace{1.5em}

\begin{itemize}[leftmargin=*, labelsep=0.5em]
\item Exact Gibbs sampling with model averaging gives calibrated 95\% prediction intervals.
\item The BIC-plus-Laplace approximation it replaces undercovers (PICP 0.00--0.18).
\item Sparsity offers no free lunch: no sparse variant beats the dense TSK baseline.
\item Corrects a membership-function bug raising dense TSK $R^2$ from 0.41 to 0.94.
\item Releases corrected code and baselines as a reproducible Bayesian TSK benchmark.
\end{itemize}
