## 1. Scope Fit（最高优先级，Seed K5）

### 1.1 定位诊断（一句话）
当前论文的标题/摘要/贡献段/结论全部「bug-fix 优先 + 负结果收尾」，是典型的「软计算/单领域」叙事，直接踩 INS scope 红线（TSK 模糊回归天然偏 Applied Soft Computing / IEEE Trans. Fuzzy Systems）。

### 1.2 定位论证段落（可直接用于 cover letter / 摘要重写基调）

> This paper contributes a general methodology for **calibrated Bayesian inference in rule-based regression under model uncertainty**, using Takagi–Sugeno–Kang fuzzy systems as the instantiation. The core object — an **exact block-Gibbs sampler for spike-and-slab priors over linear consequents, combined with Bayesian model averaging** — is not tied to building energy or to fuzzy systems specifically: it applies to any model family with linear consequents and a prior placed on rule/block inclusion. The paper's primary contribution is therefore a principled **uncertainty-quantification method** (exact posterior inference + model-averaged prediction intervals) with a **transferable diagnostic** (when analytical BIC/Laplace approximations are safe), not a single-domain soft-computing application. The reproducibility correction and the sparsity-boundary results serve as empirical validation against a correctly-constructed baseline, not as the headline.
