## 3. 分级偏离清单（合并三视角 + 主循环核验）

> 严重度定义沿用 Prompt §6：**Critical**（desk-reject / 数据诚信 / 范围路由）→ **High**（显著降录用）→ **Medium**（完整度）→ **Low**（可选）。

### 🔴 CRITICAL（2 条，投稿前必须解决）

#### C-1 · 方法的边际贡献在展示数据上≈0（种子之外的新发现，最深层问题）
- **定位**：Table 1（manuscript.tex:198-200）+ §5.2 主对比 + 摘要 headline
- **证据**：`Bayesian-TSK`（稠密共轭先验，**无稀疏**）与 `TSK-SpikeSlab-Gibbs`（本文方法）在三个目标上的 PICP 完全一致（0.95/0.94/0.95 vs 0.95/0.94/0.95），R² 也仅差 0.01。也就是说，**本文 headline 结果「校准的 95% 区间」已被自己的稠密基线达到，spike-and-slab 在 d=8 上不带来任何增益**。唯一的"赢"是打作者自己的 BIC+Laplace 流水线（PICP 0.00–0.18）。
- **为什么是 Critical**：INS 要求「original, innovative, creative」+「中心结果是可迁移洞见」。一个"与最简合法基线持平"的方法，叠加唯一对比对象是自建/自指的近似，读起来是"单域软计算应用 + 无增益"，直接触发 §P0-2.3 的第一筛选器与 ASOC 路由。
- **修法（机制性，Phase 2/3 落地）**：
  1. **补一个高维 (d>30) 无关特征 regime**，让 rule/coefficient-level 稀疏**实际打赢**稠密基线——把"边界"从 null result 转为正向 regime 刻画（这正是方法宣称价值所在，现只在 Limitations 里口头承认）；
  2. 或**加第二个模型族实例化**（basis-function / B-spline / 一般规则回归）证明 block-Gibbs/BMA 机制的通用性；
  3. 或**显式收窄声明**：把论文定位为"精确、校准的 Bayesian TSK 推断 + BIC/Laplace 解析近似失效的诊断"，不做"稀疏有增益"的暗示。

#### C-2 · 自指基线 + 无支撑优先级声明（学术诚信/可复现红线）
- **定位**：cover_letter.tex:20（"the **first** exact Bayesian inference procedure"）；manuscript.tex:46（"Recent work proposed spike-and-slab priors … but used an analytical approximation"）；cover_letter.tex:24（"recurs in published TSK code"）
- **证据**：
  - "first"优先级声明**只出现在 cover letter**，正文（标题/摘要/结论）只声称"exact"，且 Related Work 未做任何"不存在先例"的负向论证；
  - 被替换的 BIC+Laplace 基线是**作者自己早前被拒稿的流水线**（代码类 `TSK_SpikeSlab_Fast`；`figures_v2.py` 的 buggy R² 是硬编码常量，注释明写"reported in the REJECTED manuscript"），正文却以匿名"Recent work … used an analytical approximation"呈现、**无任何引用**；
  - cover letter 的"recurs in published TSK code"比正文的 hedged 表述（"an implementation we encountered"，L100）更强，无出处。
- **为什么是 Critical**：自指稻草人 + 不可验证优先级声明是 desk-reject/诚信红线；INS 审稿严苛度 4.0/5.0，第一个审稿人就会问"这个 baseline 是谁的、引用在哪"。
- **修法**：精确归因——若确有已发表的对立工作，引之并描述；若为作者早期产物，诚实承认并降为"多个说明性基线之一"；cover letter 去"first"改为"we present exact MCMC inference"（对齐正文）；"recurs in published TSK code"软化为正文同款措辞。

## 6. 是否建议投 INS（初步判断，供你决策）
